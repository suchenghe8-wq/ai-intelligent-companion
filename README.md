# AI Intelligent Companion

智能AI伴侣项目 - 一个支持会话保存、加载和管理的Python应用程序

## 项目简介

这是一个渐进式开发的AI智能对话伴侣程序，通过多个版本迭代增强功能。核心特性包括会话生成、自动保存、历史会话加载和删除管理。

## 功能列表

- **会话管理**：自动生成带时间戳的会话名称
- **会话保存**：将对话内容保存为JSON格式
- **历史加载**：查看和加载过往对话记录
- **会话删除**：删除不需要的历史会话（v6版本）

## 使用说明

运行主程序文件即可启动AI伴侣：

```bash
python "08. ai_partner_6.py"
```

首次运行会在`sessions/`目录下自动创建带时间戳的会话文件。

## 依赖项

- Python 3.x
- JSON标准库（内置）

## 注意事项

- 会话文件以`YYYY-MM-DD_HH-MM-SS.json`格式命名
- `resources/user.json`包含用户配置信息
